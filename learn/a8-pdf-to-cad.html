LESSON A8

PDF to CAD conversion

What you'll make: a CAD background you can actually design over — converted from the architect's plotted PDF, with real layers, line weights, and colors.

Video coming soon — the written steps below cover everything.

Why this beats tracing

PDFs plotted from CAD still carry their layer structure (the same data AutoCAD's PDFIMPORT reads). SprinkFlow extracts it — so the wall layer, dimension layer, and text arrive as separate, toggleable CAD layers instead of one flattened blob.

Convert a background

  1. Open Convert PDF to CAD and drop in the plan PDF. Big sets are fine — use the file picker for 100 MB+ sets.
  2. Pick the sheet from the thumbnail cards.
  3. Review the detected layers. Layers the architect had hidden come in unchecked; uncheck anything else you don't want.
  4. Set the plot scale — presets include the common ones (1/8", 1/4", 3/32"…), or type a custom scale like 3/32 or 1:50.
  5. Choose the output flavor:
    • AutoSPRINK tuned (default): line weights arrive pre-filled as Element Widths (~0.5 / 0.25 / 0.1) with colors mapped to AutoSPRINK's palette — import and go.
    • R12 DXF: maximum compatibility with older tools.
    • R2000+: carries layer lineweights and exact PDF colors for modern CAD.
  6. Convert & save — as DXF anywhere, or as DWG if the free ODA File Converter is installed (SprinkFlow links you to it if not).
Hatch dots and stipple land on their own -HATCH layer so you can freeze the noise in one click. Weight-split sub-layers (-W050/-W025/-W010) keep thick walls and thin dimensions separable even in R12.
