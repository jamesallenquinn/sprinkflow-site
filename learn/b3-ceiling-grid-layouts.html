LESSON B3

Ceiling grid layouts

What you'll learn: centering heads in ceiling tiles across whole rooms with the Place Heads in Ceiling Grid workflow.

Video coming soon — the written steps below cover everything.

Why grids are their own problem

In a lay-in ceiling, heads don't just need compliant spacing — they need to land in the tile pattern the architect drew, centered where the RCP shows them. Doing both by hand is the tedium.

Place heads in the grid

  1. Run Place Heads in Ceiling Grid over a room with a visible grid.
  2. SprinkFlow reads the room boundary and the tile pattern, and lays a per-room array — heads centered in tiles, spacing rules respected, including the minimum-separation rule between heads.
  3. Review the result room by room; the coverage audit flags anything the array couldn't satisfy so you can resolve it deliberately.
Tile snaps everywhere: even placing single heads, the smart snaps grab tile centers and grid lines — so a manual fix stays on-pattern.
