Sheets, viewports & plotting

Paper space works the way you expect: sheets at real paper sizes, viewports onto the model, and a plot that comes out at the size and scale you set.

WhatWhere you'll find it
Sheets and viewportsSide panel → Sheets tab
Title blockFile → Import Title Block (DWG)…
Draw a viewport in model spaceShift+V
Per-viewport layer settingsView → Layer View Modes
PlotCtrl+P, or the plot button in FILE

Setting up a sheet

  1. Open the Sheets tab and add a sheet. Give it a number, a name, a paper size (ARCH D, E1, or a custom size), a scale and a revision.
  2. File → Import Title Block (DWG)… brings your title block into paper space; its fields fill from the sheet's properties.
  3. Add sheet text notes anywhere — they drag and resize like everything else.

Viewports

Two kinds:

  • Unlinked — Add Viewport drops a fixed 6×4 frame you then aim and scale yourself.
  • Linked to a callout — the viewport adopts the plan callout's shape, tracks it as you reshape the callout, and renders exactly those bounds, on screen and on the plot. Draw the callout with Ctrl+Shift+A in model space, then link the viewport to it.

Right-click a viewport for the rest: Set Sheet Scale (pick from a list), Fit to Plan, Link to Callout, Lock Viewport, Rotate View, Reset View to Top, rename, label it (“DETAIL A”), and Save / Paste Camera Settings to copy one viewport's camera onto another.

Framing a viewport

Double-click a viewport — or use its pencil button — to enter frame mode. Inside it the camera gestures are the same as model space: Shift+Middle pans, the wheel zooms, Ctrl+Middle orbits. Right-click → Exit Framing when you are done, and lock the viewport so you cannot nudge it later.

Showing different things in different viewports

View → Layer View Modes carries ready-made sets — Piping Plan, Reflected Ceiling Plan, Hanger Insert Plan — and Save Current as View Mode… to make your own. Applied per viewport, so one sheet can carry a piping plan and an RCP of the same area.

Details

The detail library holds reusable details and places them onto sheets. A viewport's right-click menu also offers Create Detail Sheet to spin one up from what you are looking at.

Plotting

Ctrl+P plots to PDF. The output comes out at the real paper size, on a white background, with each viewport clipped to its frame, at roughly 300 DPI. If the project has one sheet it plots that; with several it asks which.

  • Plots always carry true line weights. The Line Weight Display slider only changes what you see on screen — it is divided back out at plot time.
  • Classification colours and weights drive the plotted appearance, which is why classifying imported linework pays off at the end as well as the beginning.
  • White-out mask borders never plot.
  • Export render PNG gives you a 300 DPI image sized against the paper, for a presentation or an email.
Known limitation: the PDF plot is currently a high-resolution raster rather than true vector output. It prints and reads correctly; it just is not selectable text and infinitely zoomable linework yet.
