Unit fill & typical layouts

On residential work most of the drawing is the same unit repeated. Design Studio finds those repeats and lets you lay out one master unit, then fill the rest.

WhatWhere you'll find it
Repeated unit listTools → Unit Blocks (Typical Units)…
Manual two-point stampTools → Stamp Unit Layout (Two-Point)
Paste into one unitRight-click inside a unit → Paste Sprinklers Into This Unit

When the architect used blocks

Tools → Unit Blocks (Typical Units)… lists every repeated block the Studio found in the imported background — that is the usual shape of an apartment drawing.

  1. Open the list. Click an instance to highlight its footprint on the plan.
  2. Lay out one instance properly — heads, and piping if you want it — as the master.
  3. Fill the rest from the list.
  4. Revise the master later and use Update from Master to re-sync everything you already filled.
Watch the match percentage. The list flags copies the architect varied. A unit at 96% is not the same unit — check it before you trust a stamped layout in it.

When the architect didn't use blocks

Plenty of drawings have the same unit drawn out longhand, over and over, with no block anywhere. Tools → Stamp Unit Layout (Two-Point) handles those:

  1. Finish the master unit's layout.
  2. Run the command and click two reference corners in the master — opposite corners of the unit are the easy choice.
  3. Click the same two corners in the next unit. The layout stamps through the transform those four points imply.
  4. Keep going — two clicks per additional unit. Esc finishes.

Mirrored units are detected from the linework, so a handed unit stamps handed without you telling it.

One unit at a time

Copy the master's heads, then right-click inside a target unit and choose Paste Sprinklers Into This Unit. Useful for the two or three odd units that do not match anything.

Tips

  • Get the master genuinely right before stamping. Fixing forty stamped units is not forty times the work, but it is not free either.
  • Classify the walls layer first (see Backgrounds & imports) — unit detection reads the real geometry, so good classification makes it better.
  • A stamp is one undo. If a unit lands wrong, Ctrl+Z and re-pick the corners.
  • Corridors, stairs and amenity spaces still need doing by hand. Unit fill is for the repeats.
