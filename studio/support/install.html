Getting started

Install & first launch

SprinkFlow Design Studio is a Windows desktop program. It installs for your user account only, so it never asks for an administrator password, and once it is licensed it runs offline.

WhatWhere you'll find it
The installerThe alpha access page — the Download for Windows button always points at the current build.
File nameSprinkFlow-Design-Studio-Alpha-Setup-vX.Y.Z.exe
After installStart Menu and a desktop shortcut, both named SprinkFlow Design Studio.

What you need

  • Windows 10 or 11, 64-bit.
  • An active SprinkFlow Tools subscription — that subscription is your Studio access. There is nothing extra to buy.
  • A real graphics card helps. The drawing view is 3D even when you are working in plan.

Install it

  1. Download the installer from the alpha access page.
  2. Run it. Windows will probably show a blue SmartScreen panel saying it protected your PC — that is because the installer is not code-signed yet, not because anything is wrong with it. Click More info, then Run anyway.
  3. It installs into your own user profile, so no administrator prompt appears. The Studio launches when it finishes.
Already have it installed? Run the new installer straight over the top. It upgrades in place and keeps your settings, your shortcuts, and your recent-projects list. You never uninstall first.

The first launch

  1. Sign in. The Studio needs a license before it will open a drawing. See Signing in & access.
  2. Read the alpha notice. A one-time dialog sets expectations: it is unfinished on purpose, it updates roughly weekly, and you are asked to report the rough edges. It reappears only when a major version lands.
  3. The launcher opens. You get New Project and your ten most recent projects. The Studio deliberately does not reopen your last job automatically — on a big drawing that would be a long wait you did not ask for.

Your name appears in the title bar next to the product name. That is normal — every licensed copy is stamped with its licensee.

Where the Studio keeps things

Your drawings live wherever you save them (.sfdp files). Everything the program keeps for itself sits under your user profile:

  • %LOCALAPPDATA%\SprinkFlow\AutoSave — crash-recovery copies.
  • %LOCALAPPDATA%\SprinkFlow\repro-bundles — diagnostic bundles you captured.
  • %LOCALAPPDATA%\SprinkFlow\bug-reports — reports waiting to upload.
  • %APPDATA%\SprinkFlow Design Platform — your preferences, keyboard shortcuts, and object defaults.

Uninstalling does not remove your drawings.

If it will not start

  • SmartScreen blocked it silently. Right-click the downloaded file → Properties → tick Unblock → OK, then run it again.
  • Corporate machine. The installer is per-user and needs no admin rights, but some managed PCs block unsigned executables outright. That one needs your IT department.
  • It opens and closes. Send us the crash note — see Crashes & recovery.
