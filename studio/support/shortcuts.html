Changing a shortcut

Open Edit → Preferences… and find the keyboard shortcut list. Every action shows its default and its current binding; click the gesture and press the keys you want. Two actions may not share a gesture — if the list ends up invalid it resets itself to the defaults rather than leaving you with keys that do nothing.

An action can carry more than one gesture; that is how the hanger tool answers both 5 and H.

The other settings

  • Edit → Default Properties… — what a newly placed object starts life as: pipe material and schedule, sprinkler K-factor and temperature, hanger type, drop style.
  • Side panel → Project — the same idea at job scale, split into Pipe, Sprinkler, Hanger, Drafting and Building. Set it once when you start the job.
  • Display & Defaults (toolbar, second row) — theme, performance mode, camera and render styles, head-layout spacing, snap kind labels, hover highlight.
Performance mode matters on big drawings. Full re-runs live analysis immediately. Draft defers the live hydraulic work and hides hydraulic node tags so drafting stays fast; the Studio selects Draft for you on very large jobs.
